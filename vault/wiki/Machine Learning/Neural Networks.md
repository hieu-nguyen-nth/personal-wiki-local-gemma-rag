# Neural Networks

Neural networks pass numeric representations through hidden layers and an output layer. Each layer transforms a vector, and training allows the network to learn useful intermediate features instead of requiring every feature to be hand-engineered. Architecture choices—such as the number of hidden layers and units—can affect performance.

The source note also connects neural networks with activation functions, multiclass classification, TensorFlow tensors and sequential layers, forward propagation, and vectorization. See [[Machine Learning Evaluation]] for the source material on model diagnosis and improvement.
