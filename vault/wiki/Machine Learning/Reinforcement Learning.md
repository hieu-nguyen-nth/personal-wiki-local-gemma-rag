# Reinforcement Learning

Reinforcement learning describes an agent observing a state, choosing an action, receiving a reward, and moving to a new state. A policy maps states to actions. A discount factor reduces the present value of rewards received farther in the future.

The source note introduces Markov decision processes, the Bellman equation, state-action values, and deep Q-learning. In deep Q-learning, a neural network approximates the value of taking an action in a state, and training repeatedly improves those estimates from experience.
