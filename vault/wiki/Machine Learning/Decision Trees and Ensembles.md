# Decision Trees and Ensembles

Decision trees repeatedly split examples using features. For classification, the source material uses entropy to measure impurity and information gain to choose a split. The splitting process continues on child branches until a stopping rule is met.

For regression trees, the split criterion is reduction in variance. Ensemble methods combine trees: bagging trains models on resampled data, random forests vary the features considered, and boosted trees focus subsequent models on examples that earlier trees handled poorly.
