# Machine Learning Evaluation

The source material separates model fitting from evaluation and emphasizes diagnosing bias and variance. It covers train, cross-validation, and test sets; regularization; learning curves; error analysis; adding data; transfer learning; and data augmentation.

Regularization trades model flexibility against overfitting. Learning curves can reveal whether more data is likely to help. Error analysis examines failed examples to identify systematic problems or useful features rather than improving a model blindly.
